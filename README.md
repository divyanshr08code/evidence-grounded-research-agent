# Evidence-Grounded Research Agent

An AI research agent designed to answer questions by retrieving and citing
verifiable evidence, rather than generating unsupported claims. The goal is
a system whose outputs are traceable back to their sources.

## Status

**Early scaffolding.** The project structure, tooling, and conventions are
being set up. The agent, retrieval pipeline, and evidence-grounding logic
have not been designed or implemented yet.

## Requirements

- Python 3.12

## Development

A `.venv` virtual environment (Python 3.12) is expected at the project root.
No dependencies are installed yet.

```sh
.venv\Scripts\activate
```

See [CLAUDE.md](CLAUDE.md) for technical context and development conventions.
